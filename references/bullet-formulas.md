# 简历经历与 Bullet 黄金公式库 (Bullet Formulas & Action Verbs)

撰写高质量简历的核心在于：**用事实说话，用动词定调，用量化定级**。

---

## 一、黄金改写模型

### 1. Google XYZ 规则
> **Accomplished [X] as measured by [Y], by doing [Z]**  
> 结构：（在 [Z] 的举措/方案下，达成了 [X] 业务或技术成果，衡量指标为 [Y]）

- **普通写法（反面教材）**：负责用户中心后端开发，参与了系统重构和性能优化。
- **XYZ 改写（高分示范）**：主导用户中心微服务重构，通过引入 Redis 多级缓存与 MySQL 读写分离机制，在日常 500 万次请求场景下，将核心接口平均响应时间从 380ms 降低至 45ms（降低 88%），支撑峰值 QPS 达 3000+。

### 2. STAR 进阶原则
- **S (Situation - 背景)**：业务痛点、系统瓶颈、老旧架构或新业务开拓诉求。
- **T (Task - 任务)**：候选人所承担的核心职责与攻坚目标。
- **A (Action - 行动)**：采用了哪些技术选型、架构设计、算法逻辑或团队协作举措（突出**主动性**与**技术深度**）。
- **R (Result - 结果)**：量化收益、业务影响、系统稳定性提升或方法论沉淀。

## 二、弱动词替换与强动词词典 (Power Action Verbs)

坚决杜绝：`负责`、`参与`、`协助`、`学习`、`做过`、`了解`。

| 业务场景 | 替代强动词推荐 (中文) | 英文强动词推荐 (English) |
| :--- | :--- | :--- |
| **架构与研发** | 主导、重构、设计、实现、攻关、搭建、抽象、沉淀 | Architected, Engineered, Developed, Spearheaded, Implemented, Designed |
| **性能与优化** | 优化、降低、提速、重组、压缩、调优、消除 | Optimized, Streamlined, Reduced, Accelerated, Refined, Enhanced |
| **运维与交付** | 部署、自动化、编排、监控、容器化、规范化 | Deployed, Automated, Orchestrated, Standardized, Containerized |
| **数据与分析** | 挖掘、清洗、建模、预测、归因、复盘、评估 | Analyzed, Modeled, Forecasted, Extracted, Evaluated, Discovered |
| **协同与管理** | 拉通、协同、驱动、推进、统筹、辅导、制定 | Orchestrated, Coordinated, Mentored, Championed, Facilitated, Governed |

## 三、缺失具体数据时的“6 维替代度量法”

当候选人记不清确切数字或因保密协议无法透露具体业务数据时，切忌编造虚假数字，改用以下维度展现深度与体量：

1. **业务与流量体量**：
   - 示范：“支撑千万级用户日常访问”、“应对日增 300GB+ 时序数据落盘”、“保障高并发秒杀峰值下零宕机”。
2. **架构复杂度与广度**：
   - 示范：“横向拉通 6 个跨业务域微服务”、“抽象封装 15+ 开箱即用通用业务组件”、“对接 8 家第三方金融机构 API 接口”。
3. **技术方案难度与对比**：
   - 示范：“对比传统轮询方案，改用 WebSocket 实时长连接机制，大幅减少无意义网络开销”。
4. **效能与交付提升**：
   - 示范：“搭建端到端 CI/CD 自动化流水线，将版本构建与全量测试时间从 45 分钟缩短至 10 分钟”。
5. **质量与健壮性**：
   - 示范：“补齐核心模块单元测试，代码覆盖率提升至 85%，上线后连续 3 个季度零 P1/P2 级生产事故”。
6. **行业认可与成果落地**：
   - 示范：“项目作为核心基建在全公司 5 个业务线全量推广落地”、“获评团队年度优秀技术创新奖”。

## 四、不同候选人画像的定制化策略

- **应届生 / 实习生**：
  - 重点突出：学术竞赛（ACM/数学建模等）、高含金量开源项目/课设、快速自学能力、团队协作精神与实习期间的具体产出。
- **跨界转行 / 转码人员**：
  - 重点突出：可迁移软技能（项目管理、商业敏锐度、逻辑沟通）、高完成度的自研端到端全栈项目、对新领域知识体系的系统化掌握。
- **资深技术专家 / 技术管理者**：
  - 重点突出：技术架构决策（选型理由与演进路线）、研发效能规范制定、技术中台孵化、人才培养与梯队搭建、技术对业务商业价值的放大倍数。
